# BH_working_prototype
This program will take any values, and will test for significance, using the Benjamini-Hochberg Procedure.

You can edit the data, mainly the "Tests" portion of the data dictionary, with any float or integer that you want.
You MUST leave the "Significance_Before variable, all as "Unsure".

If you are editing the "Tests" table, you must edit the Significance_Before table, to make it so that it has the amount of elements, that the "Tests" table has.
Again, make sure all the elements are the string "Unsure"

Libraries used were of course Pandas
I used Google Colab for this.

Prerequisites are the file, attached to the code, and GoogleColab
Best used if you run if on google colab, I am unsure if it works anywhere else.
